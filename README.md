# Vulkan Fluid Simulation

![Fluid Simulation](https://imgur.com/a/Iu6L8mi)
*Визуализация 2D SPH симуляции, работающей на GPU.*

## Описание проекта

Данный проект представляет собой высокопроизводительную **2D-симуляцию жидкости**, реализованную методом **SPH** (Smoothed Particle Hydrodynamics). Все вычисления производятся параллельно на видеокарте с использованием **Vulkan Compute Shaders**, что позволяет обрабатывать тысячи частиц в режиме реального времени.

### Ключевые особенности:
* **Полный цикл на GPU:** Все расчеты физики и обновления позиций происходят в compute-шейдерах.
* **Zero-Copy:** Данные частиц хранятся исключительно в GPU-буферах, минимизируя передачу данных между CPU и RAM.
* **Интерактивность:** Возможность изменять параметры симуляции (вязкость, гравитацию, радиус сглаживания) "на лету" через UI.

## Сборка и запуск

### Предварительные требования

Для успешной компиляции вам понадобятся:
1.  **Компилятор с поддержкой C++20** (GCC 10+, Clang 10+ или MSVC 2019+).
2.  **Vulkan SDK:** Должен быть установлен в системе и прописан в переменных окружения (`PATH`).
3.  **CMake:** Версии 3.16 или выше.

> **Примечание:** Все остальные зависимости (такие как GLFW, GLM, ImGui) будут автоматически загружены и настроены через CMake в процессе конфигурации.

### Инструкция по сборке

```bash
# 1. Клонируйте репозиторий
git clone [https://github.com/username/vulkan-fluid-sim.git](https://github.com/username/vulkan-fluid-sim.git)
cd vulkan-fluid-sim

# 2. Создайте директорию сборки
mkdir build && cd build

# 3. Сконфигурируйте проект
cmake ..

# 4. Скомпилируйте и запустите
cmake --build . --config Release
./VulkanFluidSim
